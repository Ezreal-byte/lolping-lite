# 0.1.0 验收记录

本记录区分自动化验证、Windows 本机观察与仍需真实平台验证的项目。GitHub Actions 的构建成功不能替代 macOS 权限与不同 Linux 桌面的实机验收。

## 已完成的 Windows 本机检查

- Rust 测试与 C++ 输入逻辑测试通过；输入 helper 保持原来的拖动阈值、方向判断与取消行为。
- 原生设置实际显示检查：中文、图片缩略图、分组卡片和深浅主题正常；使用 Rust / Glow 绘制，不启动 WebView2。
- 覆盖层桌面回归通过 17 个场景：四边、四角触发后返回中央，再次显示轮盘，以及空闲释放后恢复。检查画面透明度、裁剪和显示位置，没有改变光标位置或输入手势。
- 完整桌面 smoke 检查通过：配置持久化、预览、暂停和录制状态恢复、重复启停、素材导入、损坏或路径越界扩展包拒绝、重复导入，以及设置／主进程异常退出后的子进程清理。
- 生产单实例检查通过：重复启动与同时启动三次复用原有主进程、输入 helper 和设置窗口；`--quit` 正常退出完整进程树。
- 设置连续打开／关闭 20 次，均退出设置子进程，原输入 helper 未重启。主进程私有提交前五次与后五次中位数从 15.04 MiB 到 15.10 MiB，增加约 68 KiB；最后六次保持稳定。此项只统计主进程，不能和完整进程树的性能表混用。
- 新旧方案各重复三次的性能测量完成；详情见 [性能结果](performance-results-windows.md) 与匿名 [原始数据](performance-windows.json)。

Windows 安装器本机验收通过：隔离目录下安装、同版本覆盖升级、文件校验、快捷方式、默认关闭自启和卸载保留数据均正常；实际确认程序从自身安装目录加载随包提供的 Microsoft 运行库。脚本 `scripts/test-windows-installer.ps1` 遇到已有安装或用户数据会跳过，避免覆盖用户环境；CI 对应结果由 `windows-installer-report.json` 提供。

## CI 覆盖范围

- 三端执行固定依赖的 Rust / C++ 测试、原生 release 构建、资源清单和打包校验。
- Windows / macOS 使用隔离数据目录执行无桌面 smoke 检查，验证配置、导入、内部接口和生命周期；macOS runner 不授予辅助功能权限。
- Linux 使用 Ubuntu 22.04、私有 Xvfb 和正常 alpha 合成模式的 xcompmgr，检查 X11 输入、透明像素、输入穿透、不抢焦点、屏幕边缘几何、空闲缓冲释放，以及 1× / 2× GTK 缩放。桌面 smoke 检查设置进程、无托盘回退和完整退出。
- 包校验检查版本、目标架构、默认 9 个表情、可选 35 个扩展素材、SHA-256、macOS ad-hoc 签名和 Linux 安装布局。不使用本地重新编译的包替换已通过 CI 的应用产物。

本文件描述检查项目，具体提交是否全绿以 [GitHub Actions](https://github.com/Ezreal-byte/lolping-lite/actions/workflows/build.yml) 的对应记录为准。只有同一提交的三端检查全部通过后才发布 Release。

## 尚需真实平台验收

- macOS 辅助功能首次授权、拒绝后重试、升级后的授权状态，以及全屏空间覆盖行为。
- Linux 不同真实 X11 桌面的透明合成、托盘宿主、显示器布局和显卡驱动差异；Wayland 全局手势明确不支持。
- Linux 启动时缺少托盘会显示控制窗口；运行中桌面重启导致托盘宿主消失时不会主动切换，重新启动应用可打开已有实例的设置。
- Windows 多显示器混合缩放、负坐标、显示器热拔插与持续物理手势操作。当前桌面检查在单显示器 2880×1800、150% 缩放下进行。
- 自动化预览不测量物理输入到显示器的延迟；性能测试静音，未量化播放音效时的额外内存。

Windows 安装器尚未商业签名；macOS 使用 ad-hoc 签名、未公证。首次发布通过 GitHub Releases 手动更新。
