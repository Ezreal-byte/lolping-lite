# 0.2.0 设置改版验收

本次是 LOLPing Lite 独立桌面版的原生设置改版，继续使用 Rust / egui / Glow。覆盖层、输入 helper、手势判断及内部命令协议没有更换。以下本机结果来自 Windows；macOS / Linux 构建与自动化结果以同一提交的三端 CI 为准，不能替代实机显示和权限验收。

## 界面与交互

- 六个横向 TAB 实际打开检查；深色、浅色、中文和英文均显示正常。触发键、暂停热键、信号与声音、两种轮盘、素材库及应用设置全部保留。
- 默认 1120×840 和最小 760×560 窗口检查通过；窄窗改上下布局，内容滚动时顶栏、TAB 和底部保存状态保持可见。
- 系统固定 150% 显示缩放；另使用应用缩放 100% / 150% / 200% 检查布局与字体。200% 检查覆盖中英文。此项不是切换 Windows 系统 DPI，更不等同于多显示器混合缩放验收。
- 轮盘实际点击方向并分配素材后，已有素材正确交换；单纯分配不产生预览，不重启输入 helper。独立「试发信号」按钮可以显示真实透明覆盖层。
- 录制快捷键时暂停，按 Escape 取消后恢复原运行状态；超时提示保留在页面，可明确关闭。
- 实际系统文件对话框导入图片成功，素材搜索与缩略图显示正常。图片／声音／扩展包和删除的接口回归见下方 smoke。
- 截图、同尺寸设计比较、已修复的布局问题及计划内差异见 [设计 QA](../design-qa.md)。设计比较来自 UI 功能相同的 0.1.0 标识预览二进制；最终内存、生命周期和 [轮盘页补拍](images/ui-0.2.0-release-wheel.jpg) 使用已升为 0.2.0 的本机构建。

## 自动化与桌面回归

- 本轮 Rust 逻辑检查：45 项通过；唯一默认忽略的 Windows 桌面覆盖层测试另行执行并通过。覆盖轮盘八方向／中心／圆外命中、素材替换与交换、跨 TAB 待保存状态、新安装默认深色和旧主题保留。
- C++ 输入逻辑：444 项检查通过。生产手势阈值、光标位置与方向判断未改。
- Windows 覆盖层桌面测试：17 个四边、四角、返回中央和空闲释放后恢复场景通过，未出现残缺、消失或残留系统边框。
- 0.2.0 完整桌面 smoke：18 项检查通过、无跳过。覆盖配置持久化、资源校验、真实预览、重复启停、暂停／录制恢复、素材和声音导入、扩展包重复／损坏／路径越界处理、设置及主进程异常退出清理。详见 [原始结果](ui-0.2.0-smoke.json)。
- smoke 中连续开关设置 20 次通过：设置子进程退出，helper 不重启。另以正常托盘／单实例模式运行 20 次也全部通过；主进程私有提交前后中位数增加 560 KiB，最后 9 次保持稳定。结果见 [生产生命周期记录](ui-0.2.0-lifecycle.json)。
- 本地 Windows 预览 ZIP 的架构、资源、全部文件哈希、应用旁 VC 运行库和第三方许可校验通过。

## 内存复测

0.2.0 本地 release 二进制与已发布的 0.1.0 原始 ZIP 同机、交替顺序各测三轮，统计完整进程树；设置关闭后确认子进程退出并等待 22 秒空闲回收。数值、方法、二进制哈希及匿名原始样本见 [本次性能报告](performance-0.2.0-windows.md) 和 [JSON](performance-0.2.0-windows.json)。

测量使用独立测试数据、正常托盘启动及同样的预热信号；不包含 GPU 内存，不以短采样窗口代替长期泄漏测试，不声称其他设备或平台有相同结果。最终发布包由同一源码提交的 CI 构建；本机测量二进制与 CI 二进制的工具链／运行库可能不同，报告保留实际被测哈希。

## 已知边界

- macOS 辅助功能、全屏空间；Linux 真实 X11 桌面、托盘和显卡差异仍需实机验收。Wayland 全局手势仍不支持。
- Windows 多显示器混合 DPI、负坐标和显示器拔插未在本轮新增验证。
- 自动化预览不测物理输入到显示的延迟，测试为静音，不量化播放音效的额外内存。
- 既有控制器在父进程 IPC 超过 45 秒无响应时会提示错误，但仍保留未完成请求；父进程持续无响应期间设置编辑与关闭可能等待。该故障注入场景不在本次视觉改版中扩展修复。
- Windows 安装器未商业签名；macOS 使用 ad-hoc 签名、未公证。

三端 CI 执行 Rust / C++ 检查、release 构建、资源与安装包校验。Linux 另有 Xvfb / 合成器集成检查；Windows 执行用户级安装、覆盖升级和卸载检查。发布仅使用全部任务通过的同一提交的 CI 产物。
