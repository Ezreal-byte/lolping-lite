包含完整应用进程树，GPU 内存不计入；工作集相加可能重复计算共享页。先等待 22 秒空闲回收，再采样 6 秒；设置打开等待 2 秒。数值不是峰值或所有电脑的保证，短窗口 CPU 0.00% 不代表绝对不耗 CPU。每个场景均确认没有进程在采样期间退出。
