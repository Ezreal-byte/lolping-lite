# LOLPing Lite 0.3.0-Preview

这一版新增 Ubuntu 24.04 / GNOME Wayland 支持，并优化原生设置页的缩略图加载。继续使用 Rust 原生设置和覆盖层，不启动 WebView2 / Electron。当前为预发布版本，适合愿意反馈兼容性问题的用户；稳定版仍为 0.2.0。

## 本次更新

- **Ubuntu Wayland 可以启动并打信号。** 新增 GNOME Shell 46 桥接，由 Shell 负责全局组合键与桌面覆盖层，Rust 继续处理轮盘、信号／表情绘制、音频和配置。用户已在 Ubuntu 24.04.3 LTS 真机反馈可以使用。
- **优化设置窗口拖边和切页时的资源加载。** 缩略图读取、解码移到后台，加入有界队列与 LRU 缓存，并限制每次界面更新的纹理上传量；只加载可见素材，关闭设置后退出解码线程。生产垂直同步设置保持不变。
- **修复 Linux 动画缺少定时唤醒的问题。** 没有鼠标、键盘或其他请求时，动画也能继续播放，避免停在第一帧。
- **适配 Ubuntu 24.04 默认 GJS。** 帧传输改为无损 PNG，由原生 Cairo 解码，避免逐帧大 JavaScript 数组触发系统 GJS 的增量 GC 回调问题。
- **完善 Linux 打包兼容性。** 补充 AppImage 的 dconf 设置模块；显卡相关的 C++、Wayland、X11 等基础运行库使用宿主版本，减少与新系统显卡驱动冲突。
- Windows、macOS 和 X11 的原有手势、拖动阈值、方向判定、屏幕边缘修复与六类横向设置 TAB 保留。

## Ubuntu 24.04 Wayland 安装

先从托盘退出旧版，在 DEB 所在目录打开终端：

```sh
sudo apt install ./LOLPing-Lite-0.3.0-Preview-linux-x64.deb
```

无需先卸载旧版，原有配置与导入素材保留。Debian 包管理器显示版本为 `0.3.0~preview`，应用内显示 `0.3.0-Preview`，这是为正式版升级排序作的格式转换。

1. 打开 LOLPing Lite，在设置的 Wayland 提示卡点击“安装 GNOME 扩展”。
2. 保存工作，**注销 Ubuntu 并重新登录**。首次安装或升级桥接扩展都需要此步骤。
3. 确认 GNOME 扩展 **LOLPing Lite Wayland Bridge** 已启用，再打开应用点击启动／重试启动。

扩展已包含在 Linux 程序包中，不必另外下载。扩展安装到当前用户目录，无需 root、屏幕录制或 `/dev/input` 访问。

| 操作 | GNOME Wayland 快捷键 |
| --- | --- |
| 信号轮盘 | 按住 `Super + Alt + Q`，移动鼠标选方向，释放 `Q` 确认 |
| 表情轮盘 | 按住 `Super + Alt + E`，移动后释放 `E` 确认 |
| 取消 | `Esc`、鼠标右键，或在轮盘中心释放 |
| 暂停／恢复 | `Super + Alt + P` |

`Super` 就是普通键盘上的 Windows 标志键；轮盘打开后也可以左键确认。Windows / macOS / X11 保留原来的 Alt / Ctrl + 鼠标拖动方式。

## 预览版已知边界

- Wayland 当前支持 **Ubuntu 24.04 / GNOME Shell 46**，尚不支持 KDE、sway 或其他 GNOME 大版本。
- 软件渲染的虚拟 GNOME 环境里，`gnome-shell` 在 308 帧后 RSS 曾增长约 **155 MiB**，原因仍待定位。真机可以使用不等于已经完成长期内存验收；请同时观察应用和 GNOME Shell，不能只统计 Rust 进程。本版不沿用旧 Windows 报告作内存承诺。
- Windows 优化针对缩略图冷加载阻塞；偶发秒级拖边停顿尚未完成量化复测，不宣称所有设备上的长帧都已消除。
- 当前 Wayland 单显示器一帧限制为边长 4096 像素／32 MiB 解码数据。超宽屏、高缩放或相距很远的多个信号可能超过限制而停止，需要重新启动信号。
- 锁屏、休眠或扩展被禁用后可能需要重新点击启动；多屏、全屏、混合缩放等场景仍需更多实机反馈。macOS 辅助功能授权和全屏空间不能由 CI 替代验收。
- Windows 尚未商业签名；macOS 使用 ad-hoc 签名、尚未公证。

Windows 更新前退出旧版后运行安装器，或完整替换免安装目录。正常安装版沿用原有用户数据；之前独立测试启动器的隔离配置不会自动迁移。
